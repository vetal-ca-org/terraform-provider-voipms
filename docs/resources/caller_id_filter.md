# voipms_caller_id_filter (Resource)

Manages a caller-ID filter rule (`setCallerIDFiltering` / `delCallerIDFiltering`). Use `X` as a wildcard digit in `callerid`.


## Example Usage

```terraform
resource "voipms_caller_id_filter" "blocked_prefix" {
  callerid = "999XXXXXXXX"
  did      = "all"
  routing  = "sys:hangup"
  note     = "Blocked caller ID prefix"
}
```

## Schema

### Required

- `callerid` (String) Caller ID pattern (`X` matches any digit).
- `did` (String) DID this rule applies to, or `all`.
- `routing` (String) Route for matched calls, e.g. `sys:hangup`.

### Optional

- `failover_busy` (String) Busy failover route.
- `failover_noanswer` (String) No-answer failover route.
- `failover_unreachable` (String) Unreachable failover route.
- `note` (String) Note.

### Read-Only

- `id` (String) VoIP.ms filter id.

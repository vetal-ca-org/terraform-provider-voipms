# voipms_voicemail (Resource)

Manages a voicemail box (`createVoicemail` / `setVoicemail` / `delVoicemail`).


## Example Usage

```terraform
resource "voipms_voicemail" "main" {
  mailbox        = "101"
  name           = "Main"
  password       = var.voicemail_pin
  skip_password  = true
  email          = "you@example.com"
  attach_message = true
  timezone       = "America/Montreal"
  language       = "en"
}
```

## Schema

### Required

- `mailbox` (String) Mailbox number (digits). Changing this forces a new resource.
- `name` (String) Display name.
- `password` (String, Sensitive) Mailbox PIN.

### Optional

- `attach_message` (Boolean) Attach the recording to the notification email.
- `delete_message` (Boolean) Delete the message from the portal after emailing it.
- `email` (String) Notification email; comma-separated for multiple addresses.
- `email_attachment_format` (String) Attachment format (e.g. `wav49`).
- `language` (String) Prompt language (e.g. `en`).
- `play_instructions` (String) When to play instructions (`u` = unavailable greeting, etc.).
- `say_callerid` (Boolean) Announce the caller ID.
- `say_time` (Boolean) Announce the message time.
- `skip_password` (Boolean) Skip the PIN prompt when checking voicemail from a trusted DID.
- `timezone` (String) Timezone (e.g. `America/Montreal`).
- `unavailable_message_recording` (String) Unavailable greeting recording id.

### Read-Only

- `id` (String) Same as `mailbox`.

# voipms_time_condition (Data Source)

Reads a time condition by id or `name` (`getTimeConditions`). Look up by `name`, then link with `route` — do not paste a raw time condition id into a DID.


## Example Usage

```terraform
data "voipms_time_condition" "office_hours" {
  name = "Office Hours"
}

output "office_hours_route" {
  value = data.voipms_time_condition.office_hours.route
}
```

- `routing_match` (String) Where the call goes inside any of the windows.
